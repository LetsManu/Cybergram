# v0.9 UI mockup (owner-approved 2026-10-05)

Clickable original: https://claude.ai/artifact/EJ5BBu24jgf6xymjq3jWAt (private to the owner).
These `.dc.html` files are the source of that mockup (HTML/CSS reference only; `/_blob/...`
image URLs point at the portraits in `portraits/`, rendered by `render_heroes.gd` from the
game's hero models).

Direction: **premium dark** (Hextech-like, own identity). Owner's complaints about v0.8:
boxes everywhere, generic purple glow, code-drawn icons/initial badges.

- Ground ink `#0B1015`, rail `#0D1318`, deep `#080C10`, hairlines `#1E272D` / `#2A3238`
- Brass accent `#C2A267`, highlight `#EAD7A8`, dim `#6B5A38` (the ONE action colour)
- Teal `#4FB8B0` only for status (online, picking); orange `#D0904E` in-match
- Text ivory `#ECE6D6`, muted `#9AA3A8`, dim `#6C757A`
- Type: Chakra Petch (display, caps, tracking .16–.3em), IBM Plex Sans (body), IBM Plex Mono (numbers/keys)
- Hairlines and spacing instead of bordered cards; brass chamfered primary buttons; key chips
  (Q/E/C/G) in 1px brass frames; real hero portraits instead of initials; warm spotlight under heroes.
