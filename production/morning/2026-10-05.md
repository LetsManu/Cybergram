## What you need to do (about 15 minutes)

1. **Update the server (Portainer).**
   - *Stacks → cybergram → Editor*: paste the new `tools/server/docker-compose.yml`. It adds:
     - TCP port 8080 (launcher updates and server status)
     - the `cybergram-data` volume (player accounts; never delete it)
     - log rotation
     - a `tls` folder mount
   - Change `/srv/cybergram/tls` to a folder on your NAS, then *Update the stack* with *Re-pull image*.
2. **Router:** forward **TCP 8080** to the NAS, in addition to UDP 7777.
3. **TLS certificate for `cyber.djboeck.at`.** Accounts need it.
   - Without it the server runs **guest-only**, and the game automatically falls back to guest play.
   - Steps (Synology / reverse proxy / certbot): `docs/SERVER.md`, section *Player accounts and encrypted login*.
   - Afterwards the server log shows `[accounts] encrypted login enabled`.
4. **`PRIVACY.md`:** fill in `[CONTACT TO BE FILLED]` before real players register, and have someone check it. It's a draft, not legal advice.
5. **Players:** download v0.6.0, or the launcher (`CybergramLauncher-windows.zip`), which keeps the game updated from then on. v0.5.0 clients get a clear "update your game" message (protocol 13).

## Update (00:40 UTC): v0.7.0 also shipped

You told me to pick the v0.7 scope, so I chose what matters most before real players arrive:
**[v0.7.0](https://github.com/LetsManu/Cybergram/releases/tag/v0.7.0)** ([LetsManu/Cybergram#13](https://github.com/LetsManu/Cybergram/pull/13)). 678 tests pass. Full notes: `production/releases/v0.7.0.md`.

- **Forks work as designed:**
  - New mechanics: reveal (through walls, own team only), bleed and healing reduction, Hijack, a wall that blocks movement, heals that fire when a skill ends, and second-press recasts.
  - 12 fork nodes now match the design. Brannoc's Mirror and Challenge forks are still simplified.
- **Readability:**
  - Names and health bars above heroes.
  - Everyone's Forks are visible: tinted effects, Mastery diamonds and a FORKS column on the scoreboard.
  - Other players' skill casts are audible.
  - A Tutorial button in the main menu.
- **Gamepad:** full controller play, rebinding, stick options, and optional aim assist that is controller-only. It has not been tried on a real controller yet.
- **Feel:** camera recoil kick, reload, dry-fire and footstep sounds.
- **Security review:** `docs/security/review-2026-10-05.md`, 13 findings, 8 fixed. The most important:
  - A blocked encrypted connection could expose a session token. Now fixed; passwords were never exposed.
  - Login limits didn't work, and anyone could lock a player out. Now fixed.
  - Launcher updates arrived over plain HTTP, so they could be faked. Updates can now be signed, which needs your key (below).

### Extra to-dos from v0.7.0
1. **GitHub secret `FEED_SIGNING_KEY`** (signed launcher updates):
   - Run `openssl ecparam -name prime256v1 -genkey -noout -out feed_signing_key.pem` on your PC.
   - Paste the whole file as the secret's value.
   - Keep the file offline.
2. **New compose file:** deploy it in Portainer. It drops all Linux capabilities for the container.
3. **On the NAS, run once:** `chmod 700` on the accounts folder and `chmod 600` on the `*.json` files in it. Make sure `privkey.pem` isn't world-readable.
4. **Decisions for later:**
   - Password hashing strength: needs a timing test on your NAS.
   - Whether to block look-alike usernames and reserve names like "admin".
