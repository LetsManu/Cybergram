## What you need to do (about 15 minutes)

1. **Update the server (Portainer).**
   - *Stacks → cybergram → Editor*: paste the new `tools/server/docker-compose.yml`. It adds:
     - TCP port 8080 (launcher updates and server status)
     - the `cybergram-data` volume (player accounts; never delete it)
     - log rotation
     - a `tls` folder mount
   - Change `/srv/cybergram/tls` to a folder on your NAS, then *Update the stack* with *Re-pull image*.
2. **Router:** forward **TCP 8080** to the NAS, in addition to UDP 7777.
3. **TLS certificate for `cyber.djboeck.at`.** Accounts need it.
   - Without it the server runs **guest-only**, and the game automatically falls back to guest play.
   - Steps (Synology / reverse proxy / certbot): `docs/SERVER.md`, section *Player accounts and encrypted login*.
   - Afterwards the server log shows `[accounts] encrypted login enabled`.
4. **`PRIVACY.md`:** fill in `[CONTACT TO BE FILLED]` before real players register, and have someone check it. It's a draft, not legal advice.
5. **Players:** download v0.6.0, or the launcher (`CybergramLauncher-windows.zip`), which keeps the game updated from then on. v0.5.0 clients get a clear "update your game" message (protocol 13).

## Known gaps / worth a look

- **Not yet tried by a human:**
  - the game side of the launcher login hand-over (the end-to-end test used a stand-in game)
  - the online match-end screen and "Back to lobby" (covered by tests only)
  - Windows (everything was tested on Linux)
- **Forks:** some are simplified, because their full mechanic (reveal, bleed, Hijack, glide, etc.) isn't built yet. Fork values are first-pass numbers from the design document.
- **Sounds:** they're placeholder-quality synthesis, so please listen to the samples. You only hear your own skill casts; other players' casts are heard only through their effects.
- **Not done:**
  - gamepad rebinding
  - camera recoil kick
  - a tutorial replay button in the menu (use F1 in the range)
  - names above heroes' heads
- **Online play:** a logged-in player in the main menu holds a server slot. The Docker image now allows 32.
