# Cybergram v0.4.0: matchmaking lobby and lag compensation (pre-alpha)

## Download and play

| Platform | File | How to start |
|---|---|---|
| Windows 10/11 (x86_64) | `Cybergram-v0.4.0-windows-x86_64.zip` | Unzip, run `Cybergram.exe` |
| Linux (x86_64) | `Cybergram-v0.4.0-linux-x86_64.tar.gz` | Extract, run `./Cybergram.x86_64` |

No install needed. A GPU with Vulkan support is required. Windows may show a
SmartScreen warning because the build is not code-signed: choose
*More info → Run anyway*. `SHA256SUMS.txt` lists the file checksums.

## New

- **Matchmaking lobby (LoL-style flow on your server).**
  1. Press **JOIN** with the server address.
  2. See both teams, pick your hero and press **READY**.
  3. When everyone is ready, a 5 s countdown starts the 3v3 match. Bots fill
     every slot players didn't take.
  4. After the match, everyone returns to the lobby for the next one.
- **Lag compensation.** The server now judges your shots against where
  enemies were on *your* screen (up to 200 ms back), so hits at internet ping
  register fairly.
- **Shortcut:** `-- --open-lobby host:port` starts the game straight in a
  server's lobby.

**Server owners:** update the server to v0.4.0. Older clients are told
"version mismatch". Hosting guide:
[`docs/SERVER.md`](https://github.com/LetsManu/Cybergram/blob/main/docs/SERVER.md).

## Known issues

- **Matches tend to run to time-out.** Bots rarely push past the Mid or
  siege the Uplink. This needs bot AI work (see
  `design/balance/slice-tuning.md`).
- **One match per server.** No accounts, rankings or skill matching.
- **Placeholders:** sounds and models are placeholders.
