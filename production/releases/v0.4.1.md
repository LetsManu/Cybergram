# Cybergram v0.4.1: lobby fixes and server logs (pre-alpha)

## Fixed

- **Starting a match from the online lobby could break the game.** When the
  countdown ended, the lobby screen kept using its closed connection
  (a script error) instead of switching to the match. Fixed.
- **Lobby server robustness.** The lobby object is no longer freed while
  it is still running when the match starts.

## New

- **Server log.** The server log (`docker logs` / Portainer *Logs*) now shows
  every lobby step: joins, hero picks, Ready, countdown, match start, and
  players joining and leaving.
- **Log locations.** `docs/SERVER.md` lists where the server and the game
  write their logs.

## Update

- **Server:** re-pull `ghcr.io/letsmanu/cybergram-server:latest` (Portainer:
  *Update the stack* with *Re-pull image*).
- **Game:** download the v0.4.1 packages below.
