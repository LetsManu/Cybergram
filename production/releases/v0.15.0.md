# Cybergram v0.15.0: Website and public leaderboard (pre-alpha)

The network protocol changes to 18. The server and every player must update.
The launcher updates itself to 1.5.0 the first time you open it.

## Public leaderboard (opt-in)

- **New switch:** the Ranks panel has a new **"Show me on the public
  leaderboard"** switch. It is off by default.
- **What is shown:** only your display name, ranked rating and medal, and
  only while the switch is on. Guests cannot be listed.
- **Turning it off:** removes you from the board within about a minute, and
  so does deleting your account.

## The Cybergram website

A small website for the game, run as its own container next to the server:

- **Home:** download buttons for the latest release.
- **Heroes:** all seven heroes and their abilities.
- **Patch notes:** the same notes the launcher shows.
- **Server status:** up or down, players online, running matches and queue
  waits.
- **Leaderboard:** the ranked top 100, opt-in players only.
- **Impressum and privacy pages.**

There are no cookies and no trackers. Fonts are served by the site itself, so
visitors never contact third parties.

## For server hosts

The HTTP ports change so a TLS proxy can serve both sites on 80/443:

| Hostname | Host port | Serves |
|---|---|---|
| `cyber.djboeck.at` | 8080 | the website (`web` service) |
| `cyber-api.djboeck.at` | 8081 | launcher updates and status (game server) |

- **Launchers 1.5.0** fetch updates from `https://cyber-api.djboeck.at`.
  Older launchers still ask `cyber.djboeck.at:8080`. The website sends them
  on with a redirect and they switch to the new address after updating.
  - **Keep TCP 8080 forwarded** for a while.
  - **Without the website,** set `CYBERGRAM_API_PORT=8080` so old launchers
    still find their updates.
- **Starting the website:** set `COMPOSE_PROFILES=web` in `.env`. Fill the
  Impressum first: it must be complete before the site is public.
- **Server image tag:** the image now carries its own version, and the server
  logs it as `build v0.15.0` instead of `build dev`.
- **TLS from Nginx Proxy Manager:** `tools/server/sync_npm_cert.sh` copies the
  certificate NPM keeps into the server's TLS folder. It restarts the server
  only after a renewal.
- **Guide:** see `docs/HOSTING.md`, "Website".

## Privacy

`PRIVACY.md` is now version 5. It covers:
- the leaderboard opt-in (consent, how to turn it off, deletion);
- the anonymous public counts;
- the website, which keeps no IP addresses in its logs.

## Known gaps

- **Impressum and privacy pages** still contain placeholder fields to fill in
  before the website goes public.
- **Download buttons:** they read the latest release from GitHub every 6
  hours, so a brand-new release can take that long to appear.
