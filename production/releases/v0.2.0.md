# Cybergram v0.2.0: main menu, bullet tracers, first online server (pre-alpha)

## Download and play

| Platform | File | How to start |
|---|---|---|
| Windows 10/11 (x86_64) | `Cybergram-v0.2.0-windows-x86_64.zip` | Unzip, run `Cybergram.exe` |
| Linux (x86_64) | `Cybergram-v0.2.0-linux-x86_64.tar.gz` | Extract, run `./Cybergram.x86_64` |

No install needed. A GPU with Vulkan support is required. Windows may show a
SmartScreen warning because the build is not code-signed: choose
*More info → Run anyway*. `SHA256SUMS.txt` lists the file checksums.

## New

- **Main menu.** Pick your hero (Vesper Loom or Brannoc), then:
  - **Play vs Bots**: a 3v3 match on Shardline Causeway.
  - **Join** an online server by address. The last address is remembered.
  - **Movement test course**.
- **Bullet tracers.** Every shot draws a streak from the gun to where it
  landed, with a small impact spark. Your shots are yellow, allies blue,
  enemies red, so you can see where your bullets go and where fire is
  coming from.
- **Online dedicated server (first test).**
  - The Linux build doubles as a headless UDP server:
    `./Cybergram.x86_64 --headless -- --server --port 7777`.
  - Bots fill the slots players have not taken.
  - [`docs/SERVER.md`](https://github.com/LetsManu/Cybergram/blob/main/docs/SERVER.md)
    covers a VPS (systemd) and a NAS (Docker), with troubleshooting.
- **No more falling off the map.** Invisible walls above the lane-edge rails
  stop heroes from being knocked, dashing or jumping into the void. Anyone
  who still ends up below the map dies and respawns.

## Online limits in this first version

- **Teams:** every player joins the Concord team. With two players it plays
  4v3.
- **No lag compensation yet.** Shots feel late at high ping.
- **Disconnects:** a player who leaves leaves an idle hero behind.
- **Versions:** client and server must be the same version. An older client
  is told so instead of failing silently.
- **Server hardware:** x86_64 only. ARM NAS units cannot host yet.

## Known issues (unchanged)

- **Matches tend to run to time-out.** Bot matches usually end on the clock,
  not by Uplink kill, and Lumen income runs about 2× the design curve. Both
  are open design decisions.
- **Placeholder art.** Models are stylised placeholders. No audio mix yet.
