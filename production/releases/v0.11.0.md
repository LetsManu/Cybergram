# Cybergram v0.11.0: Launcher upgrade (pre-alpha)

The network protocol changes to 15, so players and the server must all be on
0.11.0. The launcher updates itself to 1.1.0 the first time you open it.

## Smaller, smarter updates

- **Only what changed:** the game now ships as a program plus separate packs:
  core, maps and HD hero textures. An update downloads only the files that
  changed, and the signed update feed checks each one.
- **Pause and resume:** a download keeps its progress. You can also limit the
  download speed in Settings.
- **Pre-load:** a new patch can download in the background before release day
  and switch on the moment it goes live.
- **Lite install:** the HD hero textures are optional. Turn them off in
  Settings > Content for a smaller download on weaker PCs.
- **Install management:**
  - change the install folder
  - repair a broken install (only damaged files download again)
  - see disk use and free space
  - uninstall the game from the launcher
- **AppImage:** the Linux AppImage now updates itself. Linux app managers can
  update it too, through its built-in update info.

## Sign in once, friends and party

- **One login:** sign in in the launcher and the game starts already signed
  in.
  - The launcher hands the game a one-time code that only works for 60
    seconds.
  - Your password is never passed to the game or stored.
- **Server panel:** Home shows whether the server is up, how many players
  are online, your ping and the server's message of the day.
- **Friends:** see who is online, and add, accept, block or remove friends,
  all from the launcher.
- **Party:** invite up to two friends. Your party joins the same lobby and
  team when the game starts.

## Patch notes and your heroes

- **Notes page:** a new NOTES page shows every patch with a version history,
  and works offline.
- **"Changes for your heroes":**
  - The top of the notes lists changes to the heroes you play most.
  - The game remembers which heroes you play on your own PC; nothing is
    uploaded. You can also pin a main in Settings.
- **Live key art:** the heroes on Home now move, with a slight parallax.
  They stay still if you turn on reduce motion.

## Settings before you play

- **Game:** set resolution, window mode and graphics quality in the launcher.
- **System check:** shows your graphics card and memory and recommends a
  quality preset. It runs only on your PC.
- **When the game starts:** the launcher can stay open, minimise or close.

## Help and privacy

- **Diagnostics zip:** Settings > Support collects the logs and basic system
  info into a zip for a bug report, with passwords and codes removed. It is
  made only when you click, and never uploaded.
- **Crash reports (opt-in):**
  - After a crash the launcher asks whether to send a report. Nothing is sent
    without your click.
  - Reports go encrypted to the Cybergram server, hold no IP address or
    account id, and are deleted after 30 days.
- **Discord (opt-in):** you can show "In lobby" or "In match" on your Discord
  profile. It is off by default and never shows your name.
- **Privacy policy:** `PRIVACY.md` (version 3) covers all of the above.

## Known gaps

- **Not tested on real systems yet:**
  - the Windows installer has only been build-checked, not run on Windows
  - the tray and minimise options when the game starts
  - Discord presence
- **Discord presence** needs a Discord application id before it can work, so
  it stays off for now.
- **Crash detection** doesn't work when the launcher is set to close as the
  game starts.
- **Language:** the language choice is English only; the game has no other
  languages yet.
- **Updates:** an install from before 0.11 downloads the full game once, then
  only changed files.
- **The installers** aren't code-signed yet.
