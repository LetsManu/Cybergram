# Cybergram v0.3.0: pause menu, settings, sound, better online slots (pre-alpha)

## Download and play

| Platform | File | How to start |
|---|---|---|
| Windows 10/11 (x86_64) | `Cybergram-v0.3.0-windows-x86_64.zip` | Unzip, run `Cybergram.exe` |
| Linux (x86_64) | `Cybergram-v0.3.0-linux-x86_64.tar.gz` | Extract, run `./Cybergram.x86_64` |

No install needed. A GPU with Vulkan support is required. Windows may show a
SmartScreen warning because the build is not code-signed: choose
*More info → Run anyway*. `SHA256SUMS.txt` lists the file checksums.

## New

- **Pause menu.** Press **Esc** (or Start on a gamepad) in a match:
  - **Resume**, **Settings**, **Leave Match** (back to the main menu), **Quit Game**.
  - The match keeps running while the menu is open. Your hero just stands
    still.
- **Settings.** Available from the main menu and the pause menu:
  - mouse sensitivity, field of view, volume, invert mouse Y, fullscreen
  - saved between sessions
- **Sound.** Placeholder combat sounds:
  - gunshots: yours, plus other heroes' positioned in 3D
  - a hit tick, higher for headshots
  - a kill chime
- **Online slots.** On a dedicated server:
  - The first player gets the reserved slot.
  - Each later player takes over a bot on the team with fewer humans, so two
    players play 3v3 against each other.
  - When someone leaves, a bot takes their hero back over.
  - The server must be v0.3.0 too.

## Known issues

- **Matches tend to run to time-out.** Bots rarely push past the Mid or siege
  the Uplink. A 3v3 tuning attempt found this needs bot AI work, not rule
  changes (see `design/balance/slice-tuning.md`).
- **Online:** no lag compensation yet.
- **Art and audio:** sounds are placeholders made in code, and models are
  stylised placeholders.
