Server logs

When you open a page, your browser sends its IP address to the web server; that is needed to deliver the page and is not stored by the website. The website writes one access log line per request with: the time, the requested path, the status code, the size of the answer and how long it took. The log contains no IP address, no browser identification (user agent) and no referring page. Error logs record only critical server faults. Logs are rotated by size (at most 3 files of 10 MB) and never shared. Purpose: running the site and finding faults. Legal basis: our legitimate interest in a working, secure website, Art. 6(1)(f) GDPR.

Server status and leaderboard

The status page shows anonymous numbers from the game server: whether it is up, players online, running matches, queue sizes and estimated waits. They say nothing about any single person.

The leaderboard shows the display name, medal and ranked rating of players who opted in with Show me on the public leaderboard in the game (under Ranks). It is off by default. Legal basis: consent, Art. 6(1)(a) GDPR, which you withdraw at any time by switching it off; you leave the list within about a minute. Deleting your game account removes you as well. No player id, username or IP address is published.

Downloads and GitHub

The game is published on GitHub (GitHub Inc., USA). The website reads the latest release information from GitHub on its own server, so just viewing this site does not contact GitHub. Only when you click a download or GitHub link does your browser go to GitHub, which then receives your IP address and browser data like any website you visit. GitHub's own privacy statement applies there: GitHub privacy statement.

Forwarding for old game launchers

Older versions of the Cybergram launcher look for game updates at this site's address. The website answers those requests (for example /version.json and the update files) with a redirect to the game server's update address (https://cyber-api.djboeck.at). The launcher then downloads from there; the website itself stores nothing about these requests beyond the access log described above. The game's privacy notice covers the update server.
