# Cybergram v0.16.0: Sound, password recovery and a findable Armory (pre-alpha)

The network protocol changes to 19. The server and every player must update.
The launcher updates itself to 1.6.0 the first time you open it.

## Sound

- **Real sound design, first pass.** Every weapon, all 28 hero skills,
  footsteps, wardlings, objectives and the menus now have their own sounds,
  with variations, instead of placeholder beeps.
- **Music.** Menu music, and match music that grows with the match and with
  nearby fights. "Reduce match music" keeps only short cues.
- **Announcer cues.** First blood, multi-kills, hardpoints, uplink under attack,
  sudden death, victory and defeat.
- **Ambience** changes between base, lane, jungle and water.
- **New settings:** Music, Announcer and Ambience volume, and Night mode for
  fewer loud peaks.

## Password recovery

- **Recovery code.** After sign-up you get a one-time recovery code. Write it
  down: there is no e-mail. You can create a new one in your profile.
- **Forgot password?** In the game and the launcher: enter your username, the
  code and a new password.
- **Long passwords fixed.** A password longer than 64 characters was cut short
  at sign-up in the game, so it then failed in the launcher. Both now agree.

## Armory

- **Easy to find.** A glowing ring on the pad, an ARMORY beacon visible from
  your spawn and an icon on the minimap.
- **Direction arrow.** When you have Lumen to spend, an arrow with the
  distance points you to the pad.

## Launcher and online

- **No more update loop.** The launcher no longer tries to update itself on
  every start, and a stuck old file no longer blocks the update.
- **Clear connection errors.** If the server does not answer, runs a
  different version or refuses the queue, you see why, with Retry and Back,
  instead of an empty screen.
- **Career page** no longer overlaps on smaller windows.

## For server hosts

- **Reset a player's password** (prints a one-time code for the player):
  `docker exec cybergram /opt/cybergram/Cybergram.x86_64 --headless --script res://src/networking/auth/account_admin_cli.gd -- --admin-reset-password <username>`
  See `docs/HOSTING.md`, "Resetting a player's password".
- **Update the server image to v0.16.0** (protocol 19).

## Privacy

`PRIVACY.md` is now version 6. Only a hash of the recovery code is stored, and
it is never exported.

## Known gaps

- Sounds were generated and measured, not yet tuned by ear in real matches.
- Some skills have a cast sound but no impact sound yet.
- Enemy reloads cannot be heard yet (not sent over the network).
- Navigation errors in offline 5v5 bot matches are still under investigation.
