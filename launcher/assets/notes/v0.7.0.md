# Cybergram v0.7.0: real fork mechanics, name plates, gamepad, security (pre-alpha)

Players need the v0.7.0 game (network protocol 14), and the server must run
v0.7.0 too.

## Forks now work as designed

There are new mechanics, so many forks no longer use stand-ins:
- **Reveal:** enemies are marked through walls for your team only.
  - Sable: Snare Charge and Sabotage Mastery.
  - Juniper: Snare Coil Mastery and the reveal part of Alarm Net.
- **Bleed and healing reduction:** Juniper's Barbed Coil.
- **Hijack:** Hex's Turncoat turns an enemy trap against its owner for a few
  seconds.
- **Blocking wall:** Brannoc's Rampart wall stops enemy heroes and lets allies
  pass.
- **Heals when a skill ends:** Brannoc's Aegis Mastery, and his Lifeblood,
  which heals 20 % of the damage absorbed.
- **Second-press recasts:** Sable's Echo snaps her back to where she started.
  Ryker's Rebound repeats the slide.
- **Interceptor:** Brannoc charges to an ally and shields you both.

## Readability

- **Name plates:** player name and health bar above heroes. Allies always show;
  enemies show when in sight and within 70 m. Mastery shows as diamonds on the
  plate.
- **Everyone's Forks are visible:**
  - Other players' skill effects are tinted cool for Fork A and warm for Fork B.
  - The scoreboard has a FORKS column.
- **Other players' skill casts are now audible** at their position.
- **Tutorial** button in the main menu.

## Gamepad

- **Full controller play.** Each action has its own gamepad binding, and you can
  rebind them in Controls under "Rebind controls for: Gamepad".
- **Stick options:** sensitivity, dead zone, response curve and invert Y.
- **Light aim assist:** controller only, can be turned off, and never applies to
  the mouse.

## Feel

- **Camera recoil kick** per weapon, which then recovers.
- **New sounds:** reload start and finish, dry fire on an empty magazine, and
  your own footsteps.

## Security

Reviewed before real players register. The full report is
`docs/security/review-2026-10-05.md`.

- **Encrypted connection blocked:** if an attacker blocks it, the game falls
  back to unencrypted guest play. It now never sends an account session over
  that unencrypted link. Passwords never were.
- **Login limits:**
  - Limits now apply per network address, so reconnecting no longer resets
    them.
  - A stranger's failed logins can no longer lock you out of your own account.
- **Changing your password signs out your other sessions.**
- **Account files** on the server are readable only by the server.
- **Signed launcher updates:** the update list can be signed. Once the owner
  creates the signing key, the launcher refuses forged updates.
- **Docker:** the container drops all Linux capabilities.

## Server update (Portainer)

1. Use the new `tools/server/docker-compose.yml`, which adds `cap_drop` and
   `no-new-privileges`. Then *Update the stack* with *Re-pull image*.
2. For signed launcher updates, create the GitHub secret `FEED_SIGNING_KEY`.
   The steps are in the security report.

## Known gaps

- Still simplified: Brannoc's Mirror and Challenge forks, and the parts of a
  few forks that involve minions.
- No HUD hint yet when a recast is available.
- Ryker's Overdrive doesn't halve the camera kick yet. The server-side spread
  is already halved.
- On a gamepad, picking a Fork with LB / RB also casts that skill.
- Not tried yet:
  - With a real gamepad: aim assist and stick feel are tuned from the maths
    only.
  - In a running game: the reveal marker and the Rampart wall have only been
    covered by tests.
