# Cybergram v0.18.0: A world that looks like its heroes (pre-alpha)

The network protocol stays at 20: v0.17 clients can still play on a v0.18
server, but they miss the fixes and the new world art below. The launcher
updates itself to 1.8.0 the first time you open it.

## World and objectives

- **Objectives at hero quality.** The Mana Uplink, the Holdstone (Hold), the
  Charge Cradle, Cell Cradles and the Mana Cell (Plant) and the **Ward
  Generator** (Breach) are now painted models in the heroes' style. The Ward
  Generator shows its shield, three crack stages and the breach, each with
  its own sound.
- **Forward Beacon.** A held Mid now shows where you would spawn: a pad with
  six lights that come on during the 15 s attunement, a light mast and banner
  when it is ready, and a dimmed, blinking light (steady with Reduce motion)
  while it is under attack and you cannot spawn there.
- **Wardlings** are rigged mini-soldiers with real walk, attack and death
  animations, in two faction looks.
- **Armory at the spawn.** You can shop inside the Sanctum, and the Armory
  pad next to it has a neon gun-shop stall.
- **Painted floors, decals and props** across the map; cover boxes are
  dressed as crate stacks. Every prop and decal is checked so nothing floats,
  sinks or blocks a path.
- **Unified look.** The map's panels use the same cel lighting as the heroes;
  important objectives get a stronger outline.

## Performance

- Wardlings cost less per tick (height from their path instead of a ground
  test every tick). A test now fails if Wardling cost goes up again.

## Connection

- **Connection test** in the launcher (Settings > Connection test): name
  lookup, UDP port, encryption and certificate, each with a plain fix.
- **Readable connect errors** in the game instead of a silent timeout (for
  example "this address is an IP; servers only accept encrypted
  connections").
- **Fixed:** joining a match dropped you back to the menu when the server had
  no public host name set.

## Fixed

- After leaving a match you were still shown as "In match" until it ended;
  you are now released when the reconnect window closes, and a match that
  everyone left ends.
- If you closed the game during a match, you stayed "In match" forever after
  it ended.
- Floor decals no longer paint on heroes or Wardlings.
- The launcher's self-update on Windows no longer fails when the running
  launcher file is locked.

## For server operators

- `/admin/accounts` lists every registered account (created, username, display
  name, last login, current state). Same admin token as `/admin`; no
  passwords or addresses.
- Refused connections are counted in `/metrics`
  (`cybergram_connections_rejected_total{reason=...}`) and logged once per
  reason every 10 s. See `docs/connecting.md`.
- Set `CYBERGRAM_PUBLIC_HOST=cyber.djboeck.at` so match connections are
  encrypted too.
