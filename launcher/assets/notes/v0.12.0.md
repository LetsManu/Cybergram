# Cybergram v0.12.0: Smoother online play (pre-alpha)

The network protocol changes to 16. The server and every player must update.
The launcher updates itself to 1.2.0 the first time you open it.

## Much less network traffic

The server now sends only what changed since your last update, packed far
more tightly.

| Shardline Front, 5v5 | Before | Now |
|---|---|---|
| Data per update | about 1.7 KB | about 0.35 KB |
| Download per player | about 51 kB/s | about 11 kB/s |
| Server upload for 10 players | about 4.1 Mbit/s | about 0.9 Mbit/s |

- **No more split updates:** every update now fits in a single network
  packet. Before, almost every update had to be split into pieces, and one
  lost piece held up the next update. That showed up as small stutters on
  connections that drop a few packets.
- **Nearby action first:** what's around you and in your view is updated
  every tick. Wardlings far away in other lanes are updated a little less
  often. Enemy heroes, objectives and abilities are always sent right away.
- **Smarter smoothing:** other players are shown slightly in the past so
  their movement looks smooth. That delay now adapts to your connection:
  about 66 ms on a steady connection, up to about 166 ms on an unsteady one.
  Before, it was always 100 ms.
- **Net graph:** the net graph (HUD settings) now shows ping, packet loss,
  jitter, data in and out, and the current smoothing delay.

## For server hosts

- Update the server image. Old clients are refused with a "version mismatch"
  message.
- Every 10 seconds the server prints one line per connected player with
  bandwidth and loss figures. It shows only connection ids, never names, and
  nothing is stored.

## Known gaps

- **Server workload:** packing updates costs the server about 0.5 ms per
  player per tick. A full 5v5 on a slow machine is still comfortably inside
  the budget, but it's the first thing to optimise if a server struggles.
- **After joining or a long dropout:** the first update shows distant
  Wardlings a few ticks late.
