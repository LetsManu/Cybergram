# Cybergram v0.6.0: talents, real weapons, practice range, smarter bots (pre-alpha)

Players need the v0.6.0 game, since the network protocol changed to 13. The
server must also run v0.6.0.

## Talent forks and mastery

- Every basic skill of all seven heroes now has **Fork A or B** (from level 5)
  and a **Mastery** (from level 9, needs a Fork). That is 63 new nodes.
- When a Fork is offered, the skill slot shows both choices. Pick one with
  **1** / **2**, rebindable, or the gamepad shoulder buttons. The choice is
  permanent for the match.
- A learned Fork shows an A/B badge with a cool or warm tint, and Mastery shows
  an M badge.
- Bots pick Forks from per-hero preferences.

## Weapons

- **Whisperfang** fires 3-round bursts, with the same damage per second as before.
- **Halo Repeater** fires real bolts with travel time, hit-checked on the
  server with lag compensation.
- Spread bloom is deterministic per shot, so there's no random noise. Ryker's
  Overdrive halves recoil.

## Practice range and tutorial

- **Practice Range** in the main menu: your hero, static and moving dummies,
  unlimited Lumen and the shop anywhere.
- Range keys:
  - **F5** level up
  - **F10** reset
  - **F1** replay the tutorial
- **First-time tutorial**, ten steps: move, jump, sprint, shoot, reload, skill,
  level up, Fork, shop, buy.
  - It shows your current key bindings.
  - You can skip it at any step.
  - Only "tutorial done" is stored.

## Match-end screen

- Shows the winner banner, and per player: hero, name, K/D/A, hero damage,
  healing, objective damage, Lumen and level, plus an **MVP**. The MVP formula
  is data.
- **Back to lobby** (online) or **Main menu**.

## Smarter bots

- **Liora** bots heal the most injured ally with the beam.
- **Sable** bots detonate Sabotage charges remotely.
- **Juniper** bots set Tripwires on the narrowest point of the enemy's path.
- **Hex** bots use Relay Hop to escape or to reposition.
- The bot roster rotates by seed, so every hero appears.

## Launcher

- **Home page:** patch notes and server status (players online, in lobby and
  in match; counts only, never names).
- **Verify / repair:** checks every file against a per-file checksum list and
  repairs anything that doesn't match. You can choose the install folder and
  move an existing install.
- **Self-update:** the launcher updates itself and checks the download's
  checksum before swapping.
- **Login in the launcher:** the game starts already signed in. The session is
  handed over in memory only, never on disk or the command line. A password is
  only ever sent over an encrypted link. Registration stays in the game.

## Sound

- Every weapon has its own synthesized gunshot.
- Every skill has a cast sound, and many have an impact sound.
- The heal beam has a looping sound.
- UI sounds: menu hover and click, level up, Fork pick, shop buy and sell.
- Sample WAVs: `production/qa/evidence/w10-sound/`.

## Server update (Portainer)

- Use *Update the stack* with *Re-pull image*.
- The image now also serves `status.json` (anonymous player counts) on TCP
  8080, next to the launcher feed.

## Known gaps

- Some Forks are simplified, because their full mechanic (reveal, bleed, Hijack,
  glide and others) doesn't exist yet.
- Other players' skill effects aren't tinted per Fork yet.
- You only hear your own skill casts. Remote casts are heard through their
  effects.
- No gamepad rebinding.
- To replay the tutorial, press F1 inside the range. There's no menu button for
  it yet.
- Not yet tried by a human:
  - The launcher login hand-over: the e2e test used a stand-in game.
  - The online match-end screen and "Back to lobby": covered by tests only.
