# Cybergram v0.1.0: first playable vertical slice (pre-alpha)

The first playable build of Cybergram, a PvP first-person MOBA shooter.
This is the M1 offline vertical slice: one lane, two heroes, bots on both
teams. It is an early pre-alpha with placeholder art and unfinished balance.

## Download and play

| Platform | File | How to start |
|---|---|---|
| Windows 10/11 (x86_64) | `Cybergram-v0.1.0-windows-x86_64.zip` | Unzip, run `Cybergram.exe` |
| Linux (x86_64) | `Cybergram-v0.1.0-linux-x86_64.tar.gz` | Extract, run `./Cybergram.x86_64` |

No install needed. A GPU with Vulkan support is required. Windows may show a
SmartScreen warning because the build is not code-signed: choose
*More info → Run anyway*. `SHA256SUMS.txt` lists the file checksums.

The game starts straight into a **3v3 match on "Shardline Causeway"**. You
play Vesper Loom, and bots fill the other five slots.

## How a match works

- **Capture hardpoints** down the lane to push the front. Wardlings, your
  AI squad, help hold and capture them.
- **Earn Lumen** from kills and objectives. Spend it at the Armory on your HQ
  pad (press F there).
- **Level up** to 6 to unlock your ultimate.
- **Win** by destroying the enemy Mana Uplink. It only takes damage once your
  team holds the enemy's Inner hardpoint.

## Controls

| Action | Key |
|---|---|
| Move / jump / sprint / crouch | WASD / Space / Shift / Ctrl |
| Fire / reload | Left mouse (click once to capture the mouse) / R |
| Skills / ultimate | Q, E, C / G |
| Learn a skill | hold Alt + Q/E/C/G |
| Interact / Armory | F |
| Med-Pack | 4 |
| Squad: smart command / wheel / follow | tap Z / hold Z / X |
| Scoreboard | Tab |
| Net graph / colour-blind mode / UI scale / damage numbers | F3 / F6 / F7–F8 / F9 |

Command-line options: `--hero brannoc` plays Brannoc instead of Vesper, and
`--map test_course` opens the movement test course.

## What's in this build

- **Heroes:** Vesper Loom and Brannoc, each with full kits and a level and
  skill-point progression.
- **Combat:** first-person weapons using Mana and Mechanical ammo.
- **Map:** Hold, Plant and Breach hardpoints and the Mana Uplink objective.
- **Wardlings:** squads with four commands, plus Vanguard waves.
- **Bots** for every empty slot, the Lumen economy and the Armory.
- **HUD:** full HUD with accessibility toggles.
- **Tech:** the server runs the simulation authoritatively at 30 Hz, and the
  client predicts locally and corrects to it. All of this runs inside one
  process.

## Known issues

- **Matches tend to run to time-out.** Bot matches usually end on the clock,
  not by Uplink kill, and Lumen income is about 2× the design curve.
- **Holes near the Outer plazas.** There are still collision gaps there.
  Anyone who falls through dies and respawns.
- **Placeholder art.** Models are stylised placeholders built in code.
  There is no audio mix and no main menu yet.
- **Offline only.** No online play yet.
